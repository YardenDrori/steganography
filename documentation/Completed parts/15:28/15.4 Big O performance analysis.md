### 15.4 חישוב יעילות האלגוריתם

המשתנים הבאים משמשים לאורך הסעיף:

- **N** = גודל צלע הבלוק (תמיד 4 בפרויקט)
- **n** = מספר המקדמים המשמשים להטמעת ביט אחד (coefficients_per_bit)
- **F** = מספר ה-I-frames בווידאו
- **W, H** = רוחב וגובה הפריים בפיקסלים
- **S** = גודל קובץ המטען בבתים
- **L** = גודל chunk ב-Reed-Solomon (עד 255 בתים)
- **P** = מספר בתי parity ב-Reed-Solomon
- **m, k** = אורכי פולינומים בחישובי GF(2⁸)

---

| אלגוריתם | סיבוכיות זמן | סיבוכיות מקום | הערות |
|----------|--------------|----------------|-------|
| DCT-II על בלוק יחיד | O(1) | O(1) | N=4 קבוע בזמן קומפילציה - תמיד בדיוק 256 פעולות. הסיבוכיות הכללית לבלוק N×N היא O(N⁴); האלגוריתם האופטימלי התיאורטי (FFT-based DCT) הוא O(N² log N) אך עבור N=4 עלות ה-FFT גבוהה מ-256 הפעולות הישירות |
| IDCT-II על בלוק יחיד | O(1) | O(1) | מבנה זהה ל-DCT, אותה הצדקה |
| הטמעת ביט - QIM | O(1) | O(1) | פעולה אריתמטית על מקדם בודד |
| הטמעת ביט - SS | O(n) | O(n) | כפל וקטורי: n פעולות. יצירת וקטור היחידה כלולה - גם O(n) |
| הטמעת ביט - ISS | O(n) | O(n) | מכפלה פנימית O(n) + עדכון מקדמים O(n) |
| הטמעת ביט - STDM | O(n) | O(n) | מכפלה פנימית O(n) + QIM O(1) + back-projection O(n) |
| חילוץ ביט - SS / ISS / STDM | O(n) | O(n) | מכפלה פנימית בלבד |
| חילוץ ביט - QIM | O(1) | O(1) | השוואת מרחקים בודדת |
| כפל בשדה GF(2⁸) - ללא טבלאות | O(log q) | O(1) | דורש אקספוננציאציה חוזרת |
| כפל בשדה GF(2⁸) - עם טבלאות | O(1) | O(q) | 2 גישות לטבלה + חיבור מודולרי. q=256 קבוע |
| כפל פולינומים ב-GF(2⁸) | O(m × k) | O(m + k) | m, k הם אורכי שני הפולינומים |
| חילוק פולינומים (חישוב שאריות) | O(m² × k) | O(m) | לולאה חיצונית O(m), כל איטרציה מבצעת כפל פולינומים O(m × k). אלגוריתמים אסימפטוטיים מהירים יותר קיימים אך מתחילים להשתלם רק עבור פולינומים בעלי מאות עד אלפי איברים - גדלי ה-chunk שלנו (עד 255) קטנים מכדי שישתלם |
| קידוד Reed-Solomon (chunk יחיד) | O(1) | O(1) | L ו-P חסומים בקבועים (L≤255), ולכן הסיבוכיות הכללית O(L² × P) היא קבועה בפועל |
| קידוד Reed-Solomon (קובץ שלם) | O(S) | O(1) | S/L chunks, כל אחד O(1). הסיבוכיות הכללית הנראית O(S × L × P) מתכנסת ל-O(S) כי L ו-P קבועים |
| Pipeline הטמעה כולל | O(F × W × H + S × n) | O(W × H) | החלק הדומיננטי הוא DCT/IDCT על כלל הבלוקים בכל I-frame. S × n הוא עלות ההטמעה עצמה |
| Pipeline חילוץ כולל | O(F × W × H + S × n) | O(W × H) | זהה להטמעה מבחינת מבנה; פריים אחד נשמר בזיכרון בכל עת לצורך קריאת הבלוקים |
